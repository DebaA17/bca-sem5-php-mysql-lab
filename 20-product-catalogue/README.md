# Code 20: E-commerce Product Catalogue

This short PHP and MySQL program displays products by category, searches for
products, and shows product details.

## Setup

1. Create the database, table, and sample products:

   ```bash
   mysql -u devuser -p < schema.sql
   ```

2. Change the database details in `config.php` if required.

3. Start the PHP server from this directory:

   ```bash
   php -S localhost:8000
   ```

4. Open <http://localhost:8000>.
